# Patch-Antenna-Design
In today's applications, the patch antenna has become one of the most important designs for RF circuits. It has many applications ranging from smartphones to wearable devices, where we need to transmit signals. The standard resonant frequency for this patch antenna is 2.4 GHz. We have designed it to operate at a frequency of 2.78 GHz.
We have attached the plot of the parametric analysis of the patch length vs. frequency, the S11 plot, the Z11 plot, the Gamma plot, the VSWR plot, and the 3D polar plot.
